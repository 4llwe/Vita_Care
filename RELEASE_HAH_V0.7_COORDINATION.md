# Vita Care HaH v0.7 — Care Coordination Hardening

Added delegated caregiver access with consent, scope, expiry, and revocation; secure episode messaging; versioned care plans; configurable/versioned EWS protocols; persistent alert events; and scheduled overdue-alert escalation from nurse to doctor to hospital referral. A reviewed SQL migration is included.

Production still requires dependency installation, generated Prisma client, migration dry-run, full tests/build/E2E, provider credentials, visual QA, clinical simulation, security testing, and regulatory approval.
