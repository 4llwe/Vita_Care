# Vita Care Hospital At Home — Platform Upgrade

Upgrade in-place terhadap project existing. Database, autentikasi, API, data pasien, dan fitur operasional tidak dihapus.

## Perubahan
- Identitas resmi, tagline, lokasi Mataram–Lombok–NTB, metadata, login, dashboard, PDF/report branding.
- Logo resmi pada header, footer, login, favicon/metadata.
- Header premium dengan 10 mega menu grid 3–4 kolom dan mobile accordion.
- Emergency modal lengkap: tim medis, rumah sakit, ambulans, keluarga, lokasi, ringkasan medis.
- Footer baru dengan layanan, pasien, bantuan, kontak, dan aksen lokal tipis.
- Placeholder aman otomatis untuk item informasi yang belum memiliki konten khusus.
- Clinical alert ditegaskan sebagai alat bantu, bukan diagnosis otomatis.
