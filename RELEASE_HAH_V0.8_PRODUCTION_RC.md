# Vita Care HaH v0.8 Production RC

Adds strict versioned EWS validation, durable notification outbox with exponential retry and delivery receipts, provider timeouts, CI production gates, safety-oriented browser tests, and release-evidence capture.

This is a production release candidate. Promotion with real patient data still requires successful CI logs, staging migration/rollback, provider delivery tests, visual QA, penetration testing, disaster recovery, clinical simulation, and signed governance/regulatory approval.
